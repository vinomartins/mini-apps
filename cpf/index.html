Por que a Aritmética Modular em ℤ₁₁ é Tão Eficiente?

O sistema de dígitos verificadores do CPF não é uma mera formalidade de cadastro: é um código detector de erros linear. A escolha do número primo p = 11 é fundamental:

  • Corpo Finito 𝔽₁₁: Como 11 é um número primo, o anel ℤ₁₁ é um corpo. Isso significa que todo número não-nulo entre 1 e 10 possui inverso multiplicativo módulo 11 (não há divisores de zero).
  • Pesos Decrescentes Distintos: Os pesos $w_i \in \{2, 3, \dots, 11\}$ são todos menores que 11 e, portanto, coprimos com 11: $\gcd(w_i, 11) = 1$.
  • Detecção de Erro em Dígito Único (100% garantida): Se um operador digitar um dígito errado $d'_i = d_i + e$ com $e \in \{-9, \dots, 9\} \setminus \{0\}$, a alteração na soma ponderada é $\Delta S = w_i \cdot e$. Como 11 é primo e não divide nem $w_i$ nem $e$, temos: $$w_i \cdot e \not\equiv 0 \pmod{11}.$$ O resto da divisão sempre se altera, garantindo 100% de detecção de erros de digitação isolados!
  • Detecção de Transposição de Dígitos Adjacentes (100% garantida): Se dois dígitos vizinhos forem trocados ($d_i d_{i+1}$ digitados como $d_{i+1} d_i$), como a diferença entre seus pesos adjacentes é exatamente 1 ($w_i - w_{i+1} = 1$), a variação na soma ponderada é: $$\Delta S = (d_i - d_{i+1}) \cdot 1 \not\equiv 0 \pmod{11} \quad (\text{sempre que } d_i \neq d_{i+1}).$$ Portanto, toda troca involuntária de dígitos consecutivos é infalivelmente interceptada.

Algoritmo em JavaScript e Python

Exemplo canônico e didático da função de validação de CPF:

function validarCPF(cpfStr) {
  // 1. Remove caracteres de formatação
  const digits = cpfStr.replace(/\D/g, '').split('').map(Number);
  if (digits.length !== 11) return false;

  // 2. Rejeita CPFs com todos os dígitos idênticos (ex: 111.111.111-11)
  if (digits.every(d => d === digits[0])) return false;

  // 3. Cálculo do Primeiro Dígito Verificador (DV1)
  let s1 = 0;
  for (let i = 0; i < 9; i++) {
    s1 += digits[i] * (10 - i); // pesos: 10, 9, 8, ..., 2
  }
  const r1 = s1 % 11;
  const dv1 = r1 < 2 ? 0 : 11 - r1;
  if (digits[9] !== dv1) return false;

  // 4. Cálculo do Segundo Dígito Verificador (DV2)
  let s2 = 0;
  for (let i = 0; i < 10; i++) {
    s2 += digits[i] * (11 - i); // pesos: 11, 10, 9, ..., 2
  }
  const r2 = s2 % 11;
  const dv2 = r2 < 2 ? 0 : 11 - r2;
  return digits[10] === dv2;
}
